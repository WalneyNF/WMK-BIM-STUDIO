Roadmap de evolução do WMK BIM Studio

Controle transparente das entregas reais, recursos herdados, iniciativas em teste e funcionalidades desejadas. Um commit não equivale a uma funcionalidade aprovada sem execução e testes.

Base: BIMCraft / RustModelo: desktop com CLI/MCPIdentidade: WMKDiferencial: plantas JPG/PNG/PDF → BIM
Como ler os status: Publicado no fork código/documentação verificado no GitHub; Protótipo independente código HTML sem integração Rust; A validar testes/build incompletos; Planejado ainda não implementado. A categoria “herdado” é explicada separadamente para evitar confusão.

1. Quais funcionalidades já são da base BIMCraft?

O projeto original já documenta os itens abaixo. Não os confundimos com melhorias criadas pela WMK; exigem testes conforme o tipo de projeto.

Arquitetura

Níveis, paredes, portas, janelas, pisos, ambientes, telhados, escadas, rampas, cortes e fachadas.

Estruturas e instalações

Vigas, pilares, fundações, armaduras, tubulações, dispositivos elétricos, quadros e dados.

Documentação

Pranchas, cotas, etiquetas, tabelas, quantitativos, plantas, vistas 3D e impressão/exportação.

Interoperabilidade e automação

IFC, DXF/DWG, leitor RVT limitado, formatos nativos, comandos, CLI e MCP.

Fase 1 — Distribuição e estabilidade

Workflow Windows Portable

Publicado no fork

Workflow GitHub Actions que compila a aplicação Rust e cria um artefato ZIP quando o build é bem-sucedido.

Aceite final: execução concluída com sucesso e ZIP disponível em Artifacts.

Build Windows e correção de CI

A validar

O primeiro workflow falhou por Cargo.lock desatualizado; houve ajuste no workflow e no formato de arquivos Rust. O build precisa ser confirmado.

Aceite: cargo build --release; cargo fmt --check; clippy; testes essenciais e inicialização real do EXE.

Ícones em executáveis e instaladores

A validar

Código Rust para ícone da janela/EXE publicado; conferir recursos binários e geração de PNG/ICO/ICNS de distribuição.

Aceite: Explorador, taskbar, menu Iniciar, atalho desktop e janelas mostrando exatamente a logo aprovada.

ZIP portátil e Release pública validada

Planejado

Verificar execução em máquina Windows comum, manual de instalação e publicação de downloads testados.

Aceite: abrir, modificar, salvar/reabrir casa exemplo sem erro e disponibilizar link público.

Fase 2 — Importar plantas JPG/PNG/PDF

Laboratório de importação de imagens/PDF

Protótipo independente

HTML/JS carrega JPG/PNG e páginas PDF (PDF.js online), calibra uma distância, permite desenhar segmentos e exporta DXF/JSON.

Aceite: conjunto de arquivos reais com casos de erro, escala, páginas e exportação; não gerar BIM falso.

Planta de referência integrada ao Rust/egui

Planejado

File picker, visualização raster com zoom/pan/rotação, escala, transparência e armazenamento no projeto nativo.

Aceite: importar 3 formatos e reabrir o projeto preservando a planta e calibração.

Traçado calibrado → parede BIM real

Planejado

Converter linhas revisadas em comandos do motor BIM para criar paredes, com pavimento, altura e espessura definidos.

Aceite: parede selecionável e editável em 2D/3D, persistente após salvar/reabrir e com undo.

Reconhecimento automático e assistido

Planejado

Pré-processamento OpenCV, classificação de paredes/aberturas, leitura de cotas por OCR e revisão visual com níveis de confiança.

Aceite: avaliação em plantas variadas, comparação com verdade de referência e correção manual antes de gerar BIM.

Casa 3D a partir de planta

Planejado

Montar paredes, portas, janelas, pisos e cobertura a partir de dados confirmados, sem inventar alturas ou estruturas.

Aceite: modelo 3D editável, geométrico consistente e exportável; relatório das suposições.

3. Sequência necessária para liberar o diferencial

  1. Estabilizar build Windows: garantir que a base alterada compila e roda.
  2. Testar importador HTML: reunir plantas de avaliação e verificar escala/linhas/exportações.
  3. Integrar imagem à GUI Rust: planta de referência persistida e navegável.
  4. Gerar paredes BIM: converter traçado manual validado em elementos paramétricos.
  5. Reconhecimento assistido: acrescentar OpenCV/OCR/IA com revisão e medidas de acerto.
  6. Produção: exportação, salvamento, pranchas e testes de aceitação.
