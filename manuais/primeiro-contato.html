Primeiro contato: instalação e uso

Testes no Windows, orientações de navegação e primeiro modelo.

1. Compilar e executar

A base é Rust e o comando Cargo mantém o nome interno bimcraft. Requer Rust 1.95+, Git e ferramentas MSVC/C++ para Windows.

git clone https://github.com/WalneyNF/WMK-BIM-STUDIO.git
cd WMK-BIM-STUDIO
cargo run --release -p bimcraft -- --sample

O fork ainda exige teste de compilação após personalizações. Não há garantia de EXE publicado no GitHub.

2. As regiões da janela

RegiãoFunção
Faixa de ferramentasArquitetura, Estrutura, Anotação, Vista, Modificar etc.
PropriedadesTipo, medidas e opções do elemento selecionado
Navegador do ProjetoPlantas por nível, vistas 3D, cortes e pranchas
Área de desenhoVisualização e edição geométrica
Barra de statusInstruções da ferramenta, mensagens e erros

3. Teste guiado de 15 ações

  1. Abra a casa de exemplo.
  2. Selecione uma parede.
  3. Veja seu tipo, altura e espessura.
  4. Altere o valor de uma propriedade simples.
  5. Confira a atualização da vista.
  6. Abra a vista 3D.
  7. Use órbita, pan e zoom.
  8. Selecione uma janela.
  9. Examine a família e o tipo.
  10. Crie uma cópia de trabalho para não sobrescrever o exemplo.
  11. Adicione uma parede em uma planta.
  12. Teste Ctrl+Z para desfazer.
  13. Abra um corte ou elevação.
  14. Confira as pranchas e quantitativos, se disponíveis no exemplo.
  15. Salve a cópia e reabra.

4. Arquivos

O aplicativo pode usar seu formato próprio .bimc, IFC e desenhos CAD conforme as funções de importação. A extensão do arquivo não garante leitura integral de todos os elementos de terceiros.

5. Português e personalização

A interface possui catálogo em português; lacunas ainda podem aparecer em inglês. Em instalações com idioma salvo, a preferência existente prevalece sobre o novo valor padrão. A autoria da personalização WMK aparece na tela inicial; a substituição completa dos ícones de instaladores ainda está pendente.

6. Erros comuns

cargo não reconhecido

Verifique se Rust está instalado e se o terminal reconhece o comando cargo --version.

Erro do linker no Windows

Instale o compilador MSVC e SDK do Windows, disponíveis com o Visual Studio Build Tools.

Aplicativo fecha ao abrir

Verifique o arquivo bimcraft.log na pasta de preferências, drivers gráficos e mensagens de inicialização.
