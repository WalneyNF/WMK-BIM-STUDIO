WMK BIM Studio
Importador de plantas baixas
JPG / PNG / PDF → calibrar escala → traçar paredes → exportar DXF/JSON

1 — Escolher a planta

PDF: visualize a página desejada (precisa de internet para carregar PDF.js nesta versão).

2 — Calibrar medidas

Escolha “Calibrar” e clique no começo e fim de uma medida conhecida da planta.

3 — Marcar paredes

Esc cancela o primeiro ponto. Mova a planta na ferramenta “Mover planta”.

4 — Exportar

O DXF pode ser importado no BIMCraft como desenho CAD. As linhas não viram paredes BIM automaticamente.

Abra uma imagem ou PDF para começar.

Arquivos são processados localmente no navegador. O PDF.js é carregado de um CDN externo, mas o arquivo não é enviado a ele por este código.
